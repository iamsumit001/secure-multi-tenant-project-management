11-Layered Security — Defense-in-Depth
Security Deep Dive

1. Multi-Tenant Scoping

Every query filtered by tenantId extracted from cryptographically verified JWT. Zero cross-org leakage.

2. Bcrypt (12 Rounds)

One-way adaptive cryptographic hashing with unique random salt. Rainbow-table proof.

3. Dual JWT Tokens

15-min short-lived Access Token + 7-day Refresh Token. No hardcoded default secret fallbacks.

4. Gmail 2FA OTP

Real SMTP email verification with 6-digit crypto OTP (15-min expiry). Blocks bot accounts.

5. Rate Limiting

express-rate-limit: Max 20 auth attempts / 15 mins. Mitigates brute-force attacks.

6. 10KB Payload Cap

express.json({ limit: "10kb" }) drops oversized malicious buffers, preventing memory DoS.

7. Helmet Headers

Enforces X-Frame-Options, X-Content-Type nosniff, and browser XSS filters automatically.

8. Strict CORS

Only whitelisted frontend origins accepted; external untrusted origins blocked with HTTP 403.

9. Granular RBAC

4 Scoped Roles: Admin, Manager, Member, Viewer with strict route permission middleware.
